# Harness Journal

> Generated from `FOUNDATION.md` by the `construct` skill. Edit
> `FOUNDATION.md`, not this file — changes here get overwritten on the
> next `construct` run.

Harness Journal is the general, reusable layer of a two-repository
pattern: every project (this one included) keeps its own `FOUNDATION.md`
— dense, complete, tool-agnostic — as its single source of truth, and
generates whatever tool-specific files it needs (`CLAUDE.md`, `AGENTS.md`,
more as new tools show up) from it, instead of hand-maintaining several
files that drift apart (the exact pain Shadow Glass's own `CLAUDE.md`/
`AGENTS.md` pair accumulated before this pattern existed).

Analogy: a compiler's front-end (this Foundation, written once) with
pluggable back-ends (each generated file, one per target reader).

## Philosophy

- **Paulo Freire** — dialogic education, not banking. Every project
  under this harness explains a concept and its trade-offs *before*
  asking for a decision, rather than deciding quietly on someone's
  behalf. See "Pedagogical approach."
- **Alberto Santos Dumont** — open, public, unpatented work. Every
  project under this harness defaults to a public repo, a visible
  decision trail (ADRs), and a diary of what was actually learned,
  mistakes included.

Working name "Harness Journal" pending a final name carrying this same
spirit.

## Structure

- `FOUNDATION.md` — the source; hand-written, never generated.
- `CLAUDE.md`, `AGENTS.md`, future tool files — generated by `construct`,
  each compressed differently for its reader.
- `docs/decisions/` — ADRs about the harness itself.
- `docs/LEARNING_LOG.md` — the diary, one entry per session.
- `.claude/agents/` — general, role-named subagents (programmer,
  observer planned first; researcher, writer, teacher, designer later).
- `.claude/skills/` — `construct` (Foundation → tool files, named after
  *Neuromancer*'s stored-knowledge constructs); a scaffolding skill for
  onboarding new tools is in design.

## Terminology

- **Skill**: repeatable, on-demand, invoked directly — no persistent
  memory between runs, but full reasoning available while it runs.
- **Agent**: a delegated worker with its own reasoning/context.
- **Field Notes**: standalone HTML explainer pages, opened locally —
  never published via Claude Code's `Artifact` tool.
- **Snapshot**: a dated visual record of a project's directory shape.
- Never "artifact" for the above — collides with Claude Code's own tool.

## Pedagogical approach

Explain before asking, for any decision the person can't yet evaluate
confidently. For low-risk/reversible calls, decide and state the
reasoning instead of blocking on a question they have no basis to
answer. Freire's dialogic principle, applied literally.

## Bilingual by design

Works naturally in Portuguese and English — same meaning, not literal
translation. Applies especially to naming.

## Commit convention

Conventional Commits: `type(scope): description`, lowercase, imperative.
