What's symlinked out, not shown above

Every agent and skill above also has a symlink in ~/.claude/agents/ or ~/.claude/skills/ — one editable source (this repo), globally invokable from any project directory. Correction, found through testing, not assumed: skills first appeared unrecognized — not because of session timing (that was wrongly suspected at first), but because they were plain <name>.md files instead of the real convention, <name>/SKILL.md. Fixed; all three loaded correctly the same session, no restart needed.

What this snapshot doesn't show

On purpose: .git/, and anything gitignored. The point of a snapshot is the shape deliberately authored, not tooling metadata.
